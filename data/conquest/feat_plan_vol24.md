# Conquest 24 (Leia, Jedi Training): the whole feat map, and which squad closes what

Source: **swgoh4.life/conquest/feats** (per-feat squad suggestions, and for each suggestion the list
of OTHER feats that same battle progresses). Cross-checked live on device 2026-09-03/04.
Squad power is Astra's own, computed from `data/roster/swgoh_roster_fresh_20260824.json`.

## The budget
572 sector keycards + 90 global = **662**, red crate at **630**, so **at most ~32 may be missed**.
Every battle has to be a node that also feeds a feat. Bonus-node farming pays 0 keycards and is a
last resort, not a plan.

⚠ **Two global feats pay a DATA DISK, not keycards.** *Undermine x50* pays Booming Voice and
*Vel x20 wins* pays Deployable Cooling Systems, and **Conquest Pass+ already granted both**. They
are worth **zero** here. Do not spend 16 battles chasing Vel. Verify the reward panel in game
before committing to any feat.

Grand Moff Tarkin · Darth Malak · Bastila Shan (Fallen), 165k, zero Attackers.**

node wins with it pays 20 feat keycards on top of 30 node keycards.
- Mini-boss Queen Amidala (7): *Darth Vader (Duel's End) in squad* / *no Empire in squad*. Mutually
  exclusive, two battles. The SEE five took the second (Sith Empire is not the Empire tag).
- **Final boss Gar Saxon (9): *win using ONLY The Stranger* / *win with Stormtrooper Luke surviving*.**
  Solo Stranger is a real ask; Stormtrooper Luke rides along in a Nightsister or GL Leia squad.
